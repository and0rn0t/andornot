## 프롬프트

당신은 마인크래프트 PvP 서버(Paper 1.21.11)용 **플랫폼 맵 생성기**를 이어서 작업합니다. 맵은 파이썬 스크립트가 Sponge schematic(.schem, v2)을 뽑고, 사용자가 WorldEdit(`//schem load`, `//paste`)로 붙여넣습니다. 서버를 직접 돌릴 수 없으니 **코드로 검증**하고, 확인 못 한 것은 "미검증"으로 표시하세요. 답변은 한국어(해요체)로 하세요.

### 1. 목표 레이아웃 (사용자의 스케치가 기준, 위에서 본 평면도)

3×3×3 큐브 퍼즐 격자의 일부만 쓰는 13조각 맵입니다. 조각 하나 = 25×25 플랫폼(조각 사이 간격 5칸, 층 사이 높이는 `H`=18). 격자 좌표 (cx, cz, cy), 평면도에서 cx=왼→오, cz=위→아래.

- **1층(cy=0): 모서리 자리 4조각** (좌상, 우상, 좌하, 우하). 가운데(코어)로 **대각선 연결부**가 이어지지만 **걸을 수 없는 장식/각도 확보용**입니다.
- **2층(cy=1): 상하좌우 4조각 + 가운데 코어 1조각.** 상·우·하·좌 4조각은 **곡선/대각선 길로 서로 이어진 사각(마름모) 순환로**입니다(상→우→하→좌→상). **가운데 코어는 순환로와 연결되지 않은 독립 블록**(검정)입니다.
- **3층(cy=2): 1층과 같은 모서리 자리 4조각.** 코어(2층 가운데)와 **걸을 수 있는 길**로 이어집니다(코어에서 3층 4조각으로 올라감).
- 평면도의 모든 연결선은 **대각선(45°)** 입니다(모서리 조각 ↔ 코어, 상/우/하/좌 조각 ↔ 이웃 조각).

> 주의: 지금 저장소의 `cube_map.py` v2 는 이 스케치를 **반대로 해석**해서, 1·3층을 상하좌우 자리에, 2층을 모서리+중앙 자리에 놓았고 길도 축 방향(직각)입니다. 이 배치를 스케치대로 **바로잡는 것이 이번 작업**입니다.

### 2. 걸어서 닿는 구역 (코드로 검증해야 함)

- {코어 + 3층 4조각}: 서로 걸어서 연결 (코어 → 3층은 오르막 길)
- {2층 상하좌우 4조각}: 순환로로 서로 연결 (코어와는 연결 안 됨)
- 1층 4조각: 각각 단독(길로 못 씀). 구역 사이 이동은 나중에 사용자가 **포탈**로 연결할 예정이므로 지금은 만들지 마세요.
- 이동기(점프 부스트 등) 없이 걷기만으로 구역 안 모든 조각에 닿아야 합니다. `mapgen/cube_map.py` 의 `reach_from()` (BFS, 1칸 오름 허용)을 유지/수정해서 위 구역이 정확히 나오는지 출력으로 증명하세요.

### 3. 디자인 요구

- 길과 테두리는 **검정**(검은 콘크리트 / 윤나는 블랙스톤 계열). 길은 폭 3.
- 색: **같은 세로줄(같은 cx,cz)** 의 조각은 같은 색, 세로줄마다 서로 다른 색. **가운데 코어는 검정**(회색 격자선으로 테두리와 구분).
- 각 조각은 윗면에 3×3 스티커 무늬(콘크리트/테라코타 번갈아 + 격자선), 옆면에도 조각 색. 단조롭지 않게 **단차 지형**(피라미드, 모서리 탑, 문 4개 아레나, 대각선 고지)을 넣어 고지 점령 싸움이 되게 함. 진입 계단은 검정.
- 밤에 싸우므로 **밝기 블록**(`minecraft:light[level=15,waterlogged=false]`)을 판 위·길 위에 숨겨 배치. 걷는 칸의 밝기(밝기 블록까지 맨해튼 거리로 근사 `15-거리`) 최소 9 이상을 목표로 하고, 이 값이 낙관적 근사임을 밝히세요. 바다등 같은 보이는 조명 블록은 쓰지 않습니다.
- 판 높이: 층 간격 `H`=18(사용자가 "플랫폼 높이를 조금 높여줘"라고 함. 해석 확인 필요). 길이 1:1 계단이라 오르막 길이가 H 이상 필요합니다.

### 4. 기술적으로 새로 풀어야 할 것

1. **대각선 길**: 지금 코드는 축 방향 계단/다리만 만듭니다. 평면 45° 길(폭 3)을 블록으로 만들어야 합니다. 방법 예: 계단식 지그재그, 대각선으로 이어붙인 정사각 발판, 대각 방향 계단(`shape=outer_left` 등 계단 `shape` 상태 활용 — 미검증). 한 번 만든 길을 걸어서 올라갈 수 있는지(점프 1칸 이내, 위 2칸 빔)를 BFS로 확인하세요.
2. **코어 → 3층 오르막**: 대각선 이웃 조각 사이 간격이 5칸이라 직선 거리가 짧습니다. H=18 을 오르려면 코어 판 위(또는 바깥)에서 길게 돌아 올라가는 길이 필요합니다. 3층 조각이 코어와 평면상 겹치지 않는 점을 이용하세요.
3. **1층 장식 연결부**: 1층 모서리 조각과 코어 사이를 대각선 지지대/버팀대로 잇되, **걸어서 닿지 않게**(윗면이 코어 바닥 아래, 1층에서 올라갈 수 없는 높이) 하세요. 장식이 길로 오해되거나 구역 BFS 결과를 바꾸면 안 됩니다.
4. 2층 순환로가 코어(가운데)와 연결되지 않으면서 3층·1층 구조물과 부딪치지 않는지(머리 공간 2칸 이상) 확인.

### 5. 현재 코드 (읽고 이어서 수정하세요)

- `mapgen/cube_map.py` : 생성기 v2. `CELL, GAP, H, T, BASE, M` 상수 / `pieces` 목록 / `origin(p)` / `build_slab` / `terrain`(지형 템플릿 4종) / `build_link`(축 방향 오르막, 대각선 미지원) / `build_loop`(가운데층 직선 다리) / `build_braces`(1층 장식 지지대) / `add_light_scan`, `add_light_fill`(밝기 블록) / `reach_from`(걷기 BFS) / `write_schem`(Sponge v2, DataVersion 3700).
  실행: `python3 mapgen/cube_map.py <출력폴더>` → `cube_map.schem`, `grid.npy`, `pal.json` 과 구역 검증 출력.
- `mapgen/preview_render.py`, `mapgen/preview_iso.py` : 등각 미리보기. 출력 폴더에서 `python3 preview_iso.py` (같은 폴더에 `grid.npy`, `pal.json`, `preview_render.py` 필요) → `iso_a.png`, `iso_b.png`, `iso_c.png`. 결과를 직접 눈으로 확인하세요.
- `mapgen/sponge_map.py` : 별개의 두 번째 맵(멩거 스펀지형, 흰 석영). 이번 작업과 무관하니 건드리지 마세요.
